# EntertainingIslandDX

<img src="docs\EntertainingIsland.jpg" alt="banner" style="zoom: 33%;" />

一个为 [ClassIsland](https://github.com/ClassIsland/ClassIsland) 设计的娱乐功能插件，让同学眼前一亮，老师眼前一黑。兼容 ClassIsland 2.0.1+。

> **本项目基于 [BSOD-MEMZ/EntertainingIsland](https://github.com/BSOD-MEMZ/EntertainingIsland) 修改而来**，原作者为 xxt8582753。
> 主要改动：移除全部全局热键与「窗外有老师警报」功能、点名器改为完全随机、头像课程表显示当堂上课时间。
> 详见 [发布说明](https://github.com/Li-Ruiqi-Code/EntertainingIslandDX/releases)。

---

## 功能概览

| 功能                 | 简介                                      |
| -------------------- | ----------------------------------------- |
| **下课倒计时** | 下课前一比一照搬 ClassIsland 内置样式提醒 |
| **小说阅读器** | 在课表上偷偷看 txt 小说                   |
| **口头禅记录** | 统计老师经典语录，支持语音识别            |
| **RSS 新闻**   | 课表上滚动显示新闻标题                    |
| **头像课程表** | 老师头像 + 科目图标展示当日课程           |
| **点名器**     | 每次完全随机的公平点名，支持 txt 导入     |
| **体育赛事**   | NBA / 英超 / 西甲等比赛实时比分           |
| **每日运势**   | 每日宜忌运势                              |
| **摄像头安全** | 摄像头被调用时显示绿色圆点提醒            |
| **自动化行动** | 15 个行动 + 2 个触发器，可按时间/状态自动触发 |

> **本插件不注册任何全局快捷键。** 需要热键类操作时，请在 ClassIsland 的「自动化」中新建规则，
> 把对应行动绑定到你自己的触发方式上（ClassIsland 自带键盘快捷键触发）。

## 下课倒计时提醒

样式 **一比一照搬 ClassIsland 内置「即将上课」**。

- 弥补 ClassIsland 只有即将上课提醒没有即将下课提醒的缺憾
- 自定义提前秒数、遮罩文字、详细文字
- 语音播报 / 强调效果 / 显示教师名称
- 设置入口：ClassIsland 设置 → **提醒** → 下课倒计时提醒

![](docs/AeroShot8.png)

## 小说阅读器

把 txt 小说放到课表上滚屏阅读。

- 自动翻页（可调间隔）
- 显示页码和进度百分比
- 点击组件暂停/继续 · 自动保存阅读进度
- 翻页与暂停也可通过自动化行动控制

![](docs/AeroShot9.png)

## 口头禅记录

记录老师或班上管纪律的说了多少次口头禅，支持语音识别自动检测。

- 完全自定义口头禅列表
- **语音识别自动检测**：通过麦克风监听，自动识别老师说的口头禅并 +1
- 可调识别灵敏度（置信度阈值）
- 可选「强调提醒」：每次 +1 时弹出 1 秒提示
- 计数入口：语音识别，或自动化行动 **口头禅 +1**

![](docs/AeroShot2.png)

## RSS 新闻

订阅 RSS/Atom 源，在课表上轮播显示。

- 自动轮播（可调间隔与标题最大长度）
- 内置一些中文源
- 加载失败时只显示「加载失败」，不暴露具体错误

![](docs/AeroShot6.png)

## 头像课程表

以老师头像 + 科目图标展示当日课程表。

- 自定义头像—科目—教师三层映射
- 已上课程自动降饱和度 + 降低透明度
- 当前课程放大 + 入场动画
  **警告：不建议为真人老师头像使用最低饱和度（黑白）效果**

![](docs/AeroShot7.png)

## 点名器

- 屏幕浮窗选择抽一人 / 抽两人
- **每一次点名都是完全独立的均匀随机**：不记历史、不加权、无保底
- 结果同步 ClassIsland 通知
- 支持 txt 导入名单

![](docs/AeroShot5.png)

## 体育赛事

实时比赛数据，来自 TheSportsDB。

- 预设 11 个主流联赛（NBA / 英超 / 西甲 / 德甲 等）
- 详细 / 简洁两种显示模式
- 可自定义数据源 URL 与自动刷新间隔

![](docs/AeroShot3.png)

## 每日运势

每日随机宜忌运势，专为高中生打造的趣味玄学指南。

- 支持自定义条目池，自由增删
- "借您吉言"模式：只显示宜，不看忌
- 一键手动刷新，换一签

![](docs/AeroShot11.png)

## 摄像头安全指示器

防止老师调用一体机前置摄像头视奸学生。

- 摄像头被调用时，主界面显示绿色圆点提醒
- 弹出动画 + 闲置时收缩为小圆点
- 可调轮询间隔（500ms ~ 10000ms）
- 支持自动化触发：摄像头开启/关闭时执行规则

![](docs/AeroShot10.png)

## ClassIsland 自动化

15 个自动化行动 + 2 个触发器，支持在 ClassIsland 规则中按时间/状态触发：

| 类型       | 行动                                       |
| ---------- | ------------------------------------------ |
| 全局组件   | 切换显隐 / 全部显示 / 全部隐藏             |
| 小说阅读器 | 暂停 / 继续 / 下一页 / 上一页 / 重新开始   |
| RSS 新闻   | 上一条 / 下一条                            |
| 口头禅     | **口头禅 +1** / 清空记录                   |
| 摄像头     | 切换监控 / 启用监控 / 禁用监控             |

| 触发器                   | 触发时机             |
| ------------------------ | -------------------- |
| 摄像头被使用时           | 摄像头状态变为「使用中」 |
| 摄像头被关闭时           | 摄像头状态变为「空闲」   |

## 安装

1. 下载 `.cipx` 插件包
2. 在 ClassIsland 中打开「插件」→「安装插件」→ 选择文件
3. 或者手动放入 `data\Plugins\entertainingisland.app\`

---

## 开发

```bash
# 构建
dotnet build -c Release

# 部署到本地 ClassIsland
.\deploy.ps1

# 打包为 .cipx 安装包（输出到 out\entertainingisland.app.cipx）
.\package.ps1
```

## 发布打包

> 建议先用 `dotnet publish -c Release`，再从 `publish/` 目录取文件。

打包为 `.cipx`（即 zip 改后缀），需包含：

- `manifest.yml` — 插件清单
- `icon.png` — 插件图标
- `EntertainingIsland.dll` — 主程序集
- `EntertainingIsland.deps.json` — 依赖清单
- `runtimes/` — .NET 运行时文件
- `README.md` — 说明文档（可选）
